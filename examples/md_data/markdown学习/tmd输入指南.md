# tmd输入指南

本篇说明当前 Tmd 的实际输入方式，介绍顺序与 [md语法详解与正文对照](md语法详解与正文对照.md) 一致。相同操作合并说明，节号范围对应详解中的各项。

文档页提供适合阅读的排版，实际仍编辑 MD；原文页用于直接检查符号和空白。本文的“正文起点”指格式标记之后、正文第一个字之前；“标记起点”指原始 `#`、`-` 等符号之前。

## 一、前缀描述

### 1.1 井号标题

行首输入一至六个 `#`，按一个普通空格，立即进入标题预览，然后继续输入标题文字。后面再输入的空格属于标题正文，不会被吞掉。

```text
输入：## + 空格 + 标题文字
原文：## 标题文字
```

- Enter 结束标题，下一行进入正常正文；Shift+Enter 相同。若在标题中间回车，前半保留标题，后半进入正文。
- 在标题正文起点按 Backspace，去掉触发空格，显示原始井号并保留文字，光标留在井号后。
- 光标已经位于第一个 `#` 之前时，再按 Backspace 才执行标题向上一行的处理：上方可见空行逐行减少；遇到普通正文时并成含真实井号的普通文本；遇到列表、引用、表格、代码等结构则不合并。
- 方向键可进入显示出的前缀，逐字符修改。想精确核对起点位置，切换原文页。

### 1.2–1.4 无序、有序与任务列表

普通列表输入 `- `、`+ `、`* ` 或 `1. `；任务项输入 `- [ ] ` 或 `- [x] `。前缀有效后进入预览，之后输入的空格和文字照常保留。

```markdown
- 普通项目
1. 有顺序的项目
- [ ] 待完成任务
```

**续写与缩进**

- Enter 在当前项后继续同级项目；在文字中间回车时，后半移到新项目，光标在后半文字最前。空列表项按 Enter 也继续生成同缩进的空项。
- 有序列表新项按当前数字加一；已有数字不重排。任务列表新项为未完成，不继承上一项的完成状态。
- Tab 进入下一层，Shift+Tab 退一级；调整父项目时，全部子项目一起移动，保持父子关系。
- 无序列表第二层显示空心圆、第三层以后显示小圆点。有序列表第二层显示字母、第三层以后显示小圆点，原文始终使用数字。
- 左键点击有序列表的编号标记，可以进入原始数字编辑；字母只是第二层的显示，不需要手写 `a. ` 创建项目。

**Backspace 与任务框**

- 光标在缩进项目的正文起点，先退一级缩进，保留项目格式；有文字和空项都适用。
- 没有缩进的普通列表，在正文起点按一次 Backspace，删除列表标记及其触发空格，本行变成普通正文；之后再按 Backspace 才尝试并入上一行。
- 空任务项先还原完整 `- [ ]` 或 `- [x]`，再按一次 Backspace 清除整个任务前缀，本行转正文。
- 空子项退一级时，紧接在后面的、原本同缩进的连续空列表项会连同行一起清理，遇到有文字项或不同层级即停止。
- 单击任务框切换勾选，并同步修改原文；Ctrl+S 保存。

### 1.5 引用、嵌套与组合容器

输入 `> ` 进入引用。需要嵌套时增加引用层，引用里也可继续输入列表或标题。

```markdown
> 引用正文
> > 第二层引用
> - 引用中的列表
```

- 有文字的引用末尾 Enter，继续下一引用段；空引用 Enter 退出一层，多层引用逐层退出。
- 引用正文起点 Backspace 去掉最内层引用前缀及其空格，文字留在当前行。
- 引用中的列表优先退出列表，保留外层引用；以后再逐层退出引用。
- 引用中的标题结束时，Enter 直接进入普通正文，同时结束标题与引用。

## 二、前后声明

### 2.1–2.4 强调、删除线与行内代码

有两种输入方式：逐字手写，或先框选文字再确认包裹。星号、下划线、波浪号和反引号的具体格式见详解相同节号；英文单引号 `'` 不用于生成行内代码。

```markdown
*斜体*，**粗体**，***组合强调***
~~删除线~~，`行内代码`
```

**逐字手写**：按原文输入开始标记、正文、结束标记；Tmd 不自动补另一端，手动配对成立后自动渲染。光标进入内容时，两端标记会展开，仍保留对应字体格式；反引号的边界与代码底色也会显示。

**选区包裹**：鼠标按住左键框选文字，再连续输入语法符号。选区和原文暂时保留，浮层显示待确认结果；输入完按 Enter 一次确认，不另起一行。

```text
框选：正文
输入：**
确认：Enter
结果原文：**正文**
```

可输入多个符号，例如两个星号、三个星号、两个波浪号；组合格式按嵌套顺序闭合。Backspace 修正待确认符号，Esc 取消并保留原选区。确认是一次编辑，可用 Ctrl+Z 撤销。

在已成对的格式内容中间按 Enter，会把现有左右标记分别留在前后段，不给两段补齐新标记；两段恢复普通字体并显示未闭合的符号。行内代码也不跨段保留代码样式。

### 2.5 代码块：创建、编辑与选择

在普通行输入三个反引号及可选语言名，按 Enter 创建；也可主动选择弹出的语言提示后确认创建。提示列表用上下键选择，Enter 或 Tab 确认；不选择语言时可保留无语言代码区。

````markdown
```cpp

```

````

上面是新代码区的基本结构：开始围栏、中间空代码行、结束围栏，以及后面的空正文输入位置；不会把后续普通文字框进代码区。

- Enter 在代码内部换行，保留当前代码缩进；Tab 到下一个四列缩进位置，Shift+Tab 减少一级。选中多行时可整体缩进或退缩进。
- Down 先在代码正文里移动，到最后一个视觉行的底部才离开代码区，进入下方普通正文；没有下方正文时提供空输入行。
- 代码首行为空且后面还有代码时，Backspace 删除该空行，让后面的行补上，保留围栏和语言；只剩独立空代码体时，才连同前后围栏一起删除。
- Ctrl+A 连续按三次，依次选择当前逻辑行、代码正文、整篇文档。前两次不含围栏；单行和空代码区也保留三个阶段。移动光标或进行其他操作后重新从行选择开始。
- 左上角显示语言，右上角复制按钮只复制该块代码正文；不同语言使用相应高亮，未知语言按普通代码显示。
- 代码区内粘贴保持字面内容。普通正文里手动输入四个行首空格只作缩进；文件导入和普通粘贴中的实际缩进代码会转成围栏代码区。

只写一条未配对围栏时保持原文；Enter 主动创建完整代码区，与把一个未闭合文件直接加载成代码区是两回事。

### 2.6 文首元数据

在原文页，把配对的 `---` 放到文件开头，中间写属性。只在文首输入 `---` 再按 Enter，不会自动补一个结束 `---`，而是到横线下方的普通正文。

```yaml
---
title: 我的笔记
tags: [学习]
---
```

完整配对后，文档页可直接编辑中间内容；点入或用方向键进入，都不展开上下边界。删除使内部内容全部为空时，属性区及前后边界一起移除。需要直接修改边界时使用原文页。

## 三、其他

### 3.1 正文、空格、换行与空行

普通正文 Enter 进入相邻下一行，Shift+Enter 除表格外采用相同规则。行首、行尾及连续普通空格都允许存在，Backspace 可逐个删除。

```text
文档页一次 Enter：下一行继续输入
原文页一次 Enter：写入一次实际换行
额外留白：继续 Enter，增加可见空行
```

文档页按需生成用于结束上一元素的原文分隔空行；显示时隐藏元素下方的第一个必要空行，额外空行才保留。不要为了让文档页出现相邻两行，手工删掉所有原文分隔。代码区、属性内部的换行按各自内容保留。

切换“文档 / 原文”时，以当前视口三分之一处的原文位置对齐到对面的三分之一处；两边都可再向下滚动约半页空白，便于继续写。

Ctrl+S 只保存当前文档；文件列表圆点提示未保存修改，关闭程序可统一保存。Ctrl+Z / Ctrl+Y 撤销和重做，两视图共享编辑历史。

Ctrl+F 打开查找，输入框里的上下键切换匹配；Tab 切换查找/替换。替换模式 Enter 只替换当前项并保持选中，直到再次搜索或关闭；Esc 关闭查找窗口。

### 3.2 下划线式标题

在文字紧邻下一行输入至少三个 `---` 或 `===`，分别形成二级或一级标题；也可在已有标记的紧邻上一行补文字。中间有额外可见空行时不合成标题。

```markdown
标题文字
---
```

标题正文起点 Backspace 先删掉下方的标题标记，文字留在当前行；再按 Backspace 才并入上一行。标题行按 Down，可以展开隐藏的标记，光标到标记末尾。

### 3.3 独立分隔线

分隔线单独成行，并与前文分开。特别是 `---`，若与上一行文字紧贴，会按下划线式标题处理。

```markdown
上文

---

下文
```

光标在分隔线下方的空正文行按 Backspace，删除整条横线；从下方按 Up 或从上方按 Down，可展开原始标记并将光标放到末尾。紧邻横线上方输入文字，会转成下划线式标题。

### 3.4 表格、对齐与格内换行

在普通行首输入 `|` 后按空格，Tmd 补齐边界并生成一行一列的表格，光标在唯一的表头格内；不是等待先手写完整分隔行才创建。

```markdown
|   |
| --- |
```

| 按键或操作 | 当前行为 |
| --- | --- |
| Tab | 换到下一单元格；整表最后一格离开到下方正文 |
| Shift+Tab | 在当前列右侧插入整列，右侧原有列后移 |
| Shift+Enter | 在当前行下方插入整行 |
| Enter | 在当前格内换行，原文用 `<br>` 保存 |
| 方向键 | 先在格内移动，达到边界后才跨格；底部 Down 退出到正文 |
| 格首 Backspace / 格尾 Delete | 不越过单元格边界删除其他内容 |
| 唯一的空格子内 Backspace | 删除整张空表，原位置留普通正文行 |
| 右键 | 删除当前行或列；删到没有行或列时移除整表 |

粘贴带 Tab 和换行的网格文本，会从当前格开始填入对应行列，缺少的行列自动扩展。载入不齐整表格时，显示与原文一起补成完整矩形；这些改动仍按 Ctrl+S 等保存规则落盘。

列对齐标记、单元格内的 `\|` 等拼写，可在原文页精确编辑。不要用普通 Enter 代替 Shift+Enter 新增表格行。

### 3.5 索引、链接与目标定义

在原文中写 `[说明](目标)`，配对后显示为链接；引用式写法按详解中的标签和定义输入。文档页单击或把光标移入链接会展开完整原文供编辑，Ctrl+左键才访问目标。

```markdown
[语法基础](md语法基础.md)
[知识树构建](tmd知识树构建.md)
```

- 当前知识库内的 MD 在 Tmd 中打开，保留其他未保存文档的编辑。
- 库外 MD、其他后缀文件交给系统默认应用；网页交给默认浏览器。相对路径从当前文档目录计算，也支持库根目录及带库名前缀的索引。
- 引用目标定义平时隐藏，方向键进入定义所在位置时展开原文编辑。自动链接的识别依赖有效边界，复杂地址优先用完整的 Markdown 链接。
- 当前文档的章节可用右侧目录定位；Ctrl+P 按标题或路径查找文档。不同阅读器的章节锚点名称可能不同。
- 文档链接是跳转入口；知识树连线需在“完善知识树”中建立，见 [tmd知识树构建](tmd知识树构建.md)。

### 3.6 图片、引用式图片与图片链接

可以粘贴图片、拖入图片文件，或手写图片 Markdown；引用式图片和图片链接的写法与详解一致。自动插入的图片保存到设置指定的统一目录，不按文档文件夹重复分层。

```markdown
![图片说明](图片路径)
```

文档页双击图片展开完整 Markdown，可修改说明和路径。光标紧邻图片之后，第一次 Backspace 选中图片，第二次删除文档中的引用；图片文件保留。

本地插入通常保存绝对路径。需要交给别人时使用携图导出，导出文件复制图片并采用相对路径；直接复制一个含本机绝对地址的 MD，不保证另一台电脑能看到图片。

### 3.7–3.8 转义、实体、HTML 与注释

需要按原样显示标点时写反斜杠转义；需要修改实体或 HTML 时直接检查其原文拼写。HTML 标签和注释在当前 Tmd 中都保留可见，不当作网页执行。

```markdown
\*字面星号\*
&amp; &#35;
<b>原始 HTML</b>
<!-- 可见的注释原文 -->
```

光标进入转义或实体位置时，展开原始拼写，Backspace 按源码逐字符删除。表格中的 `<br>` 由表格 Enter 操作生成并作为格内换行，其余 HTML 不因此启用渲染。

### 3.9–3.10 其他扩展与未完成输入

没有专用实现的公式、脚注、Wiki 双链、特殊高亮等，不靠输入符号自动增加新功能。Mermaid 等语言名仍属于代码区，不会执行或变成图形。

````markdown
[[双链]] 与 ==高亮==
$x^2$
**还未闭合
```cpp
还没有结束围栏
````

缺空格的前缀、未闭合的行内标记和不成对的围栏先保留原文；补全后才识别相应格式。普通手写不会自动补另一端；“选区输入符号后 Enter 确认包裹”和“代码围栏 Enter 创建代码区”是前面单独说明的显式操作。

看不清状态时先切到原文，确认光标、前后标记和实际换行；修改后可用 Ctrl+S 保存，再回到文档页检查。
