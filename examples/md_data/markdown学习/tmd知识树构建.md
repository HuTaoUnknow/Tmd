# tmd知识树构建

知识树说明“先学什么、接着学什么、哪里可以展开”。这里直接使用本目录的四篇文档，不另造示例节点。

## 1. 这四篇怎样连接

```text
md语法基础 ──后节点──→ tmd输入指南 ──后节点──→ tmd知识树构建
    │
    └──下节点──→ md语法详解与正文对照
```

| 起点 | 关系 | 目标 |
| --- | --- | --- |
| md语法基础 | 下节点 | md语法详解与正文对照 |
| md语法基础 | 后节点 | tmd输入指南 |
| tmd输入指南 | 后节点 | tmd知识树构建 |

“下节点”表示详解、示例等补充内容；“后节点”表示继续学习的方向。文件夹负责存放文件，这些连线负责表达知识关系，两者可以独立调整。

## 2. 在 Tmd 中操作

1. 打开 [md语法基础](md语法基础.md)，点击“知识树”，再点击“完善知识树”。
2. 把“md语法详解与正文对照”拖到基础节点的下方，观察预显示为“下节点”后松开。
3. 把“tmd输入指南”拖到基础节点的后续位置，确认关系为“后节点”。
4. 把“tmd知识树构建”连接为“tmd输入指南”的后节点。

连接后关系会保存；正文内容仍用 Ctrl+S 保存。仅在正文写一个文档链接，不会自动建立知识树连线。

## 3. 查看与调整

双击卡片切换中心，滚轮缩放，拖动空白处平移。想换一条关系，移除对应连线后重新连接。

选中卡片后使用“删除选中节点”或 Delete，会移除这个节点在树中的关系，保留对应 MD 文档。删除知识库文件与移除树中节点是两种不同操作。

先沿着“基础 → 输入指南 → 知识树构建”阅读；需要查写法和效果时，回到基础下面的 [md语法详解与正文对照](md语法详解与正文对照.md)。
