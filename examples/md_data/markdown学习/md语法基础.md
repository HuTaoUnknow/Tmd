# md语法基础

Markdown 是用普通文本记录内容、用少量符号表达结构的写作方式。`.md` 文件保存的是原文，阅读器把这些符号显示为标题、列表、代码和其他文档元素。

这篇先解决“能写一篇清楚的笔记”。需要查完整写法时，打开下节点 [md语法详解](md语法详解.md)；想直接比较写法与效果时，打开 [md语法详解示例对照](md语法详解示例对照.md)。

## 1. 用标题组织内容

标题前放 `#`，符号和文字之间留一个空格。一级标题作为文档名称，二级标题划分主要内容，三级标题细分步骤。

```markdown
# 我的学习笔记
## 今天学了什么
### 一个具体问题
```

- `#` 到 `######` 分别对应一到六级标题。
- 尽量按层级展开，让右侧目录容易浏览。
- 标题描述具体问题，例如“如何处理空输入”，比“其他”更容易检索。

## 2. 用空行分段

两段文字之间留一个空行。同一段中的普通换行不一定表现为新的段落；希望内容分段时，用空行最清楚。

```markdown
第一段解释问题。

第二段记录自己的解决过程。
```

## 3. 区分重点与代码

- `**重点**` 显示为 **重点**。
- `*需要强调的语气*` 显示为 *需要强调的语气*。
- 单个反引号包住短代码，例如 `System.out.println()`，适合表示命令、变量和文件名。
- 多行代码用代码围栏包住。开头可以写语言名称，帮助支持它的阅读器识别代码。

````markdown
```java
String topic = "Markdown";
System.out.println("今天学习：" + topic);
```
````

代码围栏内的文字会作为代码保留。不要把普通段落都放进代码块，否则标题和列表也只会显示为原样文本。

## 4. 用列表记录知识点和步骤

```markdown
- 先描述问题
- 再记录做法
- 最后写出结果

1. 新建笔记
2. 整理内容
3. 保存文件
```

- 无顺序的要点使用 `-`。
- 必须依次执行的过程使用数字列表。
- 嵌套内容放在所属项目下面，并缩进，避免它变成独立段落。

## 5. 引用与链接

引用前加 `>`，适合摘录一句话或突出一条提醒。

> 笔记先让自己看懂，再考虑排版是否漂亮。

链接使用 `[显示文字](目标地址)`。同一个目录里的文档可以写相对路径：

```markdown
[继续了解 tmd](tmd作用及其意义.md)
```

链接负责跳转，知识树负责表达学习关系。仅在正文里写链接，不会自动创建前节点、后节点或下节点。

## 6. 第一次练习

- [ ] 写一个一级标题和两个二级标题。
- [ ] 写两段自己的学习总结，段落之间留空行。
- [ ] 添加一个列表、一段行内代码和一个代码块。
- [ ] 在“原文”中查看符号，在“文档”中查看效果。
- [ ] 保存后重新打开，确认内容还在。

任务列表、表格和删除线等属于常见扩展语法，具体显示由阅读器决定；详解和对照文档会继续展示。
