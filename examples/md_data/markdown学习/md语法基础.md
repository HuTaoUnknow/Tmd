# md语法基础

Markdown 用少量符号组织普通文本，文件后缀是 `.md`。先掌握下面四类写法，再阅读下节点 [md语法详解与正文对照](md语法详解与正文对照.md)。

## 1. 标题

行首写一至六个 `#`，后面留一个空格，再写标题；井号越多，标题层级越深。

```markdown
# 学习笔记
## 本章内容
### 一个小节
```

## 2. 代码块

多行代码放在前后成对的三反引号之间。起始行可写语言名，例如 `cpp`、`html`、`xml`。

````markdown
```cpp
int count = 3;
```
````

## 3. 无序列表与有序列表

没有先后顺序的要点用 `- `；有步骤顺序的内容用 `1. `、`2. `。标记与文字之间留空格。

```markdown
- 标题
- 代码块

1. 阅读说明
2. 自己输入
3. 保存笔记
```

## 4. 表格

竖线 `|` 分列，第二行用 `---` 分隔表头与数据；每行保持相同列数。

```markdown
| 项目 | 用途 |
| --- | --- |
| 标题 | 组织层次 |
| 列表 | 记录要点 |
```
