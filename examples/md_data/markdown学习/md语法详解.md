# md语法详解

这篇是 [md语法基础](md语法基础.md) 的下节点，按用途整理常用写法。需要直接查看原文与排版效果时，打开 [md语法详解示例对照](md语法详解示例对照.md)。

## 1. 标题与段落

```markdown
# 文档名称
## 主要章节
### 小节

第一段说明背景。

第二段说明结论。
```

- `#` 标题可使用一到六级，符号后留空格。
- 标题上下留空行，原文更容易阅读。
- 空行划分段落；普通换行在不同阅读器中可能表现为软换行。
- 需要强制换行时，可以在行末放两个空格，或使用反斜杠后换行。普通叙述优先使用自然段。

另有使用 `===` 或 `---` 放在下一行的一级、二级标题写法。初学时统一使用 `#` 更容易区分标题与分隔线。

## 2. 强调、删除线与行内代码

```markdown
**关键结论**
*需要强调的一句话*
***加粗并倾斜***
~~已经过时的做法~~
命令 `java -version` 用于查看本地版本信息。
```

- 加粗用于重点；斜体用于语气或术语，避免整段都加粗。
- 删除线是 GFM 扩展，使用两个 `~` 包住内容。
- 行内代码适合短命令、函数名、变量和路径。
- 代码文字本身含有一个反引号时，外面可以用两个反引号包住：

```markdown
``包含 ` 这个符号``
```

不要把引号 `'` 或中文顿号误当成反引号 `` ` ``。

## 3. 多行代码与代码围栏

````markdown
```java
int count = 3;
if (count > 0) {
    System.out.println("还有学习任务");
}
```
````

- 代码围栏至少使用三个反引号，也可以使用三个波浪号。
- 开头和结尾使用同一种符号，结尾长度不能短于开头。
- `java`、`javascript`、`json` 等语言标记提示代码类型；是否高亮取决于阅读器。
- 代码块内部保留缩进，不再按普通 Markdown 段落解析。
- 需要展示三反引号本身时，外层用四个反引号。例如本节的“原文”展示就是这样包住的。

代码块适合真实代码、配置或需要保留格式的输出。普通说明放在代码块外，阅读起来更清楚。

## 4. 无序、有序与嵌套列表

```markdown
- 后端
  - Java 基础
  - HTTP 接口
- 前端
  - 页面结构
  - 页面交互

1. 确定目标
2. 完成练习
3. 检查结果
```

- `-`、`+`、`*` 可以作为无序列表标记，统一一种即可。
- 有序列表使用数字加点；需要顺序清楚时，原文也按顺序编号。
- 子项目需要缩进到父项目内容下面。无序列表通常两个空格就能形成子项；其他块内容根据父项目标记宽度对齐。
- 列表里放多段文字或代码块时，留空行并维持相应缩进。

## 5. 任务列表

```markdown
- [x] 已完成语法入门
- [ ] 写一篇自己的笔记
- [ ] 补上学习复盘
```

任务列表是 GFM 扩展。方括号内空格表示未完成，`x` 表示已完成。文档中的任务状态是笔记内容，修改后需要保存。

## 6. 引用与分隔线

```markdown
> 我把遇到的问题记下来，方便下一次定位。
>
> 第二段引用前也保留引用标记。

---

分隔线下面开始新的主题。
```

- `>` 可以嵌套，也可以包含列表。
- 引用适合摘录或提醒，引用他人的文字时补充来源。
- `---` 可作为分隔线，单独占一行并在上下留空行，减少与二级标题写法混淆。

## 7. 链接与图片

```markdown
[回到入门](md语法基础.md)
[CommonMark 语法帮助](https://commonmark.org/help/)
![学习闭环示意](../../md_photo/markdown学习/学习闭环.png)
```

- 文档相对地址从当前 `.md` 所在文件夹开始计算。
- `..` 表示向上一级目录。本组文档在 `md_data/markdown学习`，因此图片先向上两级到项目根目录，再进入 `md_photo/markdown学习`。
- 图片前比普通链接多一个 `!`；方括号中的文字描述图片内容。
- 路径建议使用 `/`。含空格的目标可以用尖括号包住，例如 `[笔记](<我的 笔记.md>)`。
- 图床使用可访问的 `https://` 地址；绝对路径对应某台电脑的位置，分享时通常没有相对路径方便。

重复使用的链接也可以写成引用式：

```markdown
查看 [入门文档][basic]，或者把它分享给同学。

[basic]: md语法基础.md
```

## 8. 表格与对齐

```markdown
| 知识点 | 练习 | 完成次数 |
| :--- | :---: | ---: |
| 标题 | 写一个章节 | 1 |
| 列表 | 整理学习步骤 | 2 |
```

表格是 GFM 扩展。表头下面一行使用连字符分隔；冒号在左侧、两侧、右侧分别表示左对齐、居中、右对齐。

- 每一行尽量维持相同列数。
- 单元格中需要出现竖线时，写成 `\|`，避免它变成新的列。
- 表格适合简短对照，长段落和多行代码适合放在表格外。

## 9. 转义与符号原样显示

```markdown
\*这段星号作为普通文字显示\*
\# 这里不是标题
```

在有语法作用的标点前加 `\`，可以把它作为普通符号显示。大量符号或一整段代码直接放进代码围栏更方便。

## 10. 区分通用语法与扩展

- 标题、段落、强调、列表、引用、链接、图片、代码等属于常用 Markdown 内容。
- GFM 在 CommonMark 基础上提供表格、任务列表、删除线等扩展。
- 脚注、数学公式、图表代码以及部分 HTML 展示依赖阅读器额外支持。不要只凭文件里写了符号，就认为所有软件都会显示相同效果。
- 分享前打开导出的文件，检查代码、表格、链接和图片是否符合预期。
