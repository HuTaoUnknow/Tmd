## 3. 多行代码

**原文**

````markdown
```java
String subject = "Java 基础";
int practiceCount = 2;
System.out.println(subject + "：练习 " + practiceCount + " 次");
```
````

**文档效果**

```java
String subject = "Java 基础";
int practiceCount = 2;
System.out.println(subject + "：练习 " + practiceCount + " 次");
```

这里对照的是代码的展示方式；Markdown 文档不会执行这段程序。
