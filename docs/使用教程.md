# Tmd 使用教程

[English](USER_GUIDE.md) · [安装与备份](INSTALLATION.md) · [项目首页](../README.md)

## 1. 找到自己的知识库

安装版默认在系统“文档”目录的 `Tmd` 文件夹中保存知识：

```text
Tmd/
├─ md_data/                   Markdown 文档与关系
│  ├─ markdown学习/           五篇入门示例
│  └─ .tree-md-relations.json  知识关系
└─ md_photo/                  文档中的本地图片
```

便携版使用程序旁的这两个目录。正文中的图片路径从当前 `.md` 所在文件夹计算。备份时把 `md_data`、`md_photo` 一起复制，并保留隐藏的关系文件。

### 文件列表右键操作

右键点击某篇 Markdown 文档，可重命名或将它移入 Windows 系统回收站，操作对象始终是点击的那篇文档。右键点击目录可在其中新建文件夹或删除整个目录；右键列表空白区域会在 `md_data` 根目录新建文件夹。空文件夹同样显示在列表中。

删除目录会把目录及其全部子文件一起移入回收站。当前文档有未保存的编辑时，可先保存、放弃编辑或取消操作。文件菜单的“删除”也使用回收站；回收站操作失败时不会永久删除。相关知识树连线会清理，`md_photo` 图片保留，方便还原和其他文档继续引用。还原文件后按 F5 刷新，已清理的知识树关系需要重新连接。

## 2. 写第一篇笔记

1. 选择“文件 → 新建”，输入 `我的学习/第一篇笔记.md`。
2. 写一个一级标题、两个二级标题，以及一段自己的理解。
3. 切换“文档 / 原文”检查排版和实际语法。
4. 按 `Ctrl+S` 保存。

```markdown
# 我的第一篇学习笔记

## 问题

我想了解怎样把笔记连接成一条学习路线。

## 实践与复盘

- 写清一个主题。
- 找到它需要的基础。
- 记录下一步能做的事情。
```

“文档”也支持直接编辑。需要精确调整表格、图片地址和代码围栏时，使用“原文”；两个视图共享撤销记录。切换文档会保留各篇未保存的编辑，文件列表右侧以灰白色圆点提示。`Ctrl+S` 只保存当前文档；关闭 Tmd 时统一提示“全部保存”“不保存”或“取消”。保存失败时窗口保持打开，失败文档的编辑内容和圆点保留。

文档模式中，输入标题、列表、编号列表或引用前缀后按空格，会立即进入对应预览样式；后续空格和文字属于正文，行尾空格也会保留。在缩进列表正文起点按 Backspace，先退一级缩进并保留列表，空列表项也遵循这个规则。没有缩进且正文为空时，Backspace 去掉触发空格并显示原始前缀，任务项完整显示 `- [ ]` 或 `- [x]`；再按空格即可恢复预览。左右键仍可进入前缀，逐字修改符号。

普通正文每次回车直接到下一行，额外空行和普通行首、行尾空格都保留。标题中间回车时，前半保持标题，后半转为正文。`---` 或 `===` 紧邻上一行文字时生成二级或一级标题，仅作用于上一行；标题正文开头退格删除下划线，向下键可进入真实下划线编辑。

空列表回车仍创建同级空项；退格先退缩进，再还原前缀，再转为本行正文。父项改变缩进时全部子项一起移动。引用正文回车继续引用段，空引用回车、引用正文开头退格均逐层退出；引用中的标题回车直接进入普通正文。

代码围栏输入完成后按 Enter，或主动选择语言提示，创建独立代码区及下方空正文行。代码中向下键逐行移动，到最后一行才离开代码区。空代码首行退格让后续代码补上；只有独立空代码体才连同围栏一起删除。手动输入四个行首空格保持普通缩进；文件导入或普通粘贴中的实际缩进代码会转为围栏代码。代码区内部粘贴保持原样。

行首 `|` 后输入空格生成一行一列表格。Tab 换格，末格 Tab 进入下方正文；Shift+Tab 在当前列右侧添加整列，Shift+Enter 在当前行下添加整行，普通 Enter 在本格换行。方向键先在格内移动，到边界再跨格，底部 Down 进入正文。右键可删除行、列；唯一空格子处 Backspace 删除整张表。普通格首 Backspace 不影响前一格。粘贴制表符网格时自动扩展行列；已有缺格表格会同步补齐文档和原文，Ctrl+S 保存。

链接单击编辑、Ctrl+单击打开；光标进入时展开完整 Markdown。图片双击展开原文，图片后第一次 Backspace 选中图片、第二次删除引用，保留图片文件。实体与转义在光标进入时展开拼写。HTML 全部显示原文，表格内 `<br>` 换行除外。行内加粗、斜体、删除线和代码均手动配对，拆段不补全标记。Shift+Enter 除表格新增行外均与 Enter 相同。

完整格式、原文示例与按键约定见 [语法规则记录](syntax-review/RULES.md)，30 类语法卡片见 [确认模板](syntax-review/README.md)。

## 3. 找文档与找标题

- 左侧目录按真实文件路径组织文档。
- `Ctrl+P` 打开快捷搜索，输入标题或路径中的关键词；方向键选择，回车打开，Esc 关闭。
- 顶栏“目录”打开右侧标题列表，点击标题定位到正文相应部分。
- `Ctrl+滚轮` 缩放正文，范围 50%～200%；`Ctrl+0` 恢复 100%。

左侧变窄时会变成图标与搜索按钮；继续拖窄会完全隐藏。竖屏时自动缩略，更窄的竖屏隐藏左右目录，此时仍可用 `Ctrl+P` 搜索，并手动点击“目录”显示标题。

## 4. 建立知识树

打开一篇文档，点击“知识树”，再点击“完善知识树”。左侧列出当前范围内尚未显示的文档，右侧展示以当前文档为中心、最多五层关系的树。

| 关系 | 什么时候用 | 如何理解 |
| --- | --- | --- |
| 前节点 | 当前知识需要的基础 | 先学 A，再学 B |
| 后节点 | 学完以后继续的方向 | B 是 A 的后续，A 也是 B 的基础 |
| 上节点 | 同级可替换的方案 | 两个方案共用前后的学习路线 |
| 下节点 | 详解、案例、练习 | 依附于主题，可以继续嵌套 |

1. 从左侧把文档拖向右侧某张卡片。
2. 观察虚线预显示和关系文字，确认连接对象与方向。
3. 松开鼠标保存关系。
4. 已有卡片也可以拖动到另一张卡片，或从连接点开始拖动。

主路线横向排列，上节点贴在主卡片上方，下节点以小卡片放在下方并用折线连接。点击连线后按 Delete 或“移除选中连线”解除关系，文档保留。双击卡片可改用该文档为中心重新索引。

选中卡片后，点击“删除选中节点”或按 Delete，一次移除该节点的全部连线，对应 MD 文档及未保存编辑保留。断开后未显示的文档回到左侧列表，可重新连接。删除中心节点会切换到树中剩余节点；清空当前树后，双击左侧文档即可重新建立中心。

切换中心会保留同一棵树的卡片位置、大小和连线。中心改变只更新高亮和五层显示范围；仅修改关系时重新计算布局。

滚轮缩放画布，拖动空白区域平移，双击空白区域回到当前节点附近。知识树缩放独立于正文字体，并自动保存；超过五层或未连接的文档继续放在左侧列表。

## 5. 插入图片

在编辑区域粘贴截图、复制的图片文件，或拖入图片。默认统一复制到知识库旁的 `md_photo`，平铺保存，不按文档目录分层；正文使用绝对路径，原图片保留。相同内容的图片共用一份文件，携图导出时才改为相对路径。

点击“设置 → 图片保存方式”打开独立窗口，顶部横排三种方式，选好后点击“应用”：

- **相对目录**：以 `md_data` 为基准选择保存目录，默认 `../md_photo`。界面显示实际位置，图片平铺保存并使用绝对引用。
- **绝对目录**：默认方式，指定完整保存目录。留空时使用知识库旁的 `md_photo`；本地图片和截图统一复制到此目录，以绝对路径引用。
- **图床**：管理图片链接的名称、地址和默认项，支持新增、编辑、删除及插入；删除记录不会删除服务器图片或文档中的引用。

配置上传接口后，图床方式下粘贴或拖入图片会通过 POST multipart/form-data 上传，成功后插入返回的图片链接。可配置接口 URL、文件字段、返回链接的 JSON 字段路径（如 `data.url`）、请求头/表单/查询参数鉴权、凭据前缀及附加表单参数。接口留空时，已有链接照常使用，本地图片保存到统一目录并使用绝对引用。此接口尚未接入真实图床验证。

Token/Key 输入框的凭据使用 Windows DPAPI 本机保护保存，导出时省略；迁移电脑或切换服务后需重新填写。目录设置只影响后续插入的图片，已有图片和文档地址保留。

在应用中重命名、移动或另存为时，程序会维护图片引用，并把其他目录中引用的本地图片复制到统一目录。使用外部软件移动文档时，自行检查图片路径；F5 可刷新正文与图片。

## 6. 导入、另存为与导出

- **导入**：把已有 Markdown 加入当前知识库，同时复制可读取的本地、内嵌图片。
- **另存为新文档**：在知识库内建立副本。
- **导出 Markdown**：保存到外部目录，可勾选“携带图片”，一起复制图片到导出文件同级目录。

携带导出只修改导出副本的图片地址。任一图片不可读取时，导出会报告失败；检查文件位置或网络连接后重试。单篇导出分享的是文档和图片；分享完整知识树需要同时带上关系数据。

## 7. 外部编辑与备份

Tmd 可以检测外部文件变化。未修改的文档自动刷新，尚未保存的编辑会保留并提示冲突。先判断要保留哪一版，再保存或重新加载。

定期备份 `md_data` 和 `md_photo`。升级前关闭 Tmd 并保留备份。安装版卸载只移除程序文件与相关注册，不删除“文档/Tmd”中的知识库。

## 8. 设置字体与 Markdown 排版

点击“设置 → MD加载样式”，五个大项默认折叠，点击带箭头的条目展开详细选项。首选字体和次选字体分别用于正文与缺失字符的回退，代码字体单独设置。支持六级标题大小、行距、分点缩进、引用背景、代码块与行内代码背景、表格配色等；正文缩放继续以这些字号的 100% 为基准。

输入三个反引号后会显示代码语言提示，继续输入可筛选，Tab 或 Enter 补全，Esc 关闭，Ctrl+Space 再次打开。文档和原文模式均支持，语言提示、语法高亮、代码换行与编辑时自动预加载可以分别开关。

成对代码围栏在文档模式显示独立的代码面板，左上角显示语言名称（例如 HTML、XML、C++），右上角的复制图标只复制该代码块的代码正文，保留空行、Tab 与换行，不带围栏和后面的正文。复制后短暂显示“已复制”，不改变当前选区和编辑位置。未指定语言显示“纯文本”；不成对的反引号继续按原文显示。

文档与原文中的代码按围栏指定的语言配色：HTML/XML 区分标签、属性与属性值，C/C++ 区分类型、关键字和预处理指令，其他语言按各自的字符串、注释、数字与函数规则高亮。HTML/Vue 的 script 和 style 内容使用 JavaScript/CSS 规则，跨行注释不会染到下一个代码块。纯文本和未知语言保持普通文字颜色；“语法高亮”开关只控制配色，不影响复制和语言标签。

点击“应用”保存并立即更新当前文档。设置自动保存在界面下方显示的 `Tmd-settings.txt` 路径，开关按位打包、数值和颜色采用紧凑字段、字体采用 UTF-8，再转成十六进制 TXT。程序缓存已解析的设置，应用时采用原子写入。

窗口最下方使用“导入配置”“导出配置”转移十六进制 TXT。导出包含图片位置等配置参数，不包含文档、图片文件和 Token/Key 凭据；导入后先检查，再点击“应用”。损坏文件会提示错误并保留当前设置。旧版配置仍可读取，图片新增参数采用默认值。取消和未经应用的“恢复默认”不会修改已保存的设置。“关于 Tmd”也位于“设置”菜单。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Ctrl+N | 新建 |
| Ctrl+S | 保存 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+P | 快捷搜索 |
| Ctrl+Shift+D | 文档模式 |
| Ctrl+Shift+M | 原文模式 |
| Ctrl+Shift+O | 切换目录 |
| Ctrl+Shift+K | 切换知识树 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
