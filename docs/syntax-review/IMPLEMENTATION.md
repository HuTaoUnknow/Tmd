## 2026-10-19：N58 列表层级标记

顶层为第一层。无序列表依次显示实心圆、空心圆、小实心圆；有序列表依次显示数字、小写字母、小实心圆，第四层以后保持第三层样式。第二层按原文数字对应字母，保留手写跳号，26 对应 z、27 对应 aa；0 没有对应字母时仍显示 0。原文继续使用数字，字母不是新增的源码前缀。左键点击数字、字母或有序深层圆点后进入真实数字前缀编辑，离开后恢复预览。任务框保留勾选入口。
