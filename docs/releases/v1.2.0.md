# Tmd v1.2.0 — 版本介绍 / Release introduction

发布日期：2026-11-05。面向 Windows 10/11 x64。

Tmd 把 Markdown 文档编辑、图片和知识树放在同一个本地知识库中。文档页方便阅读和书写，原文页保留可直接编辑的 Markdown；知识树连接学习路线、替代方案、详解与实例。

## 本版更新

- 默认打开方式：设置中可登记 Tmd 为当前用户打开 `.md` 的可选程序，再由 Windows“默认应用 / 打开方式”确认；Debug 版经 `Start-Debug.ps1` 启动，安装版直接启动；双击 MD 交给已有窗口，并沿用库外文档备份询问；可移除登记，卸载时清理。
- 单实例：同一程序与知识库复用已有窗口，重复启动的 MD 交给该窗口；覆盖并发启动与异常退出恢复。
- 库外文档：拖放或 Ctrl+O 打开库外 MD，可选根目录备份或直接编辑原件；侧栏独立显示路径，缺失标红，保留未保存与冲突保护。
- 查找替换：文档内查找与替换、圆角匹配高亮、方向键切换，并保留当前替换结果选区。
- 显示与编辑：中文标点旁粗体渲染、轻量表格样式与表头加粗、多表格打开卡顿修复；列表层级标记（空心圆 / 小圆点 / 字母）且保留数字原文。
- 导航与库维护：Ctrl+单击本库文档、外部文件与网页；移动后自动修正引用，缺失目标红点，全库 MD 文件名唯一。
- 教程与回归：更新四篇 Markdown/Tmd 教程及公开知识树示例；回归检查增至二十二组。

## 安装与启动

1. 安装版：运行 `Tmd-1.2.0-Windows-x64-Setup.exe`，选择程序目录和快捷方式，之后通过桌面或开始菜单启动。
2. 便携版：完整解压 `Tmd-1.2.0-Windows-x64-Portable.zip` 到可写目录，双击 `Start-Tmd.cmd` 或 `tree_md.exe`。启动器、EXE、DLL、插件应保留在同一套解压目录中。
3. 便携版的 `md_data` / `md_photo` 位于程序旁；安装版使用系统“文档\Tmd”。升级前可备份整个知识库，保留隐藏的关系文件。
4. `Ctrl+S` 保存当前文档，右侧“文档 / 原文”切换显示，`Ctrl+P` 搜索。详细说明见随包 `README.md` 与 `docs/使用教程.md`。

下载校验使用同页的 `SHA256SUMS.txt`。随包仅包含公开入门示例；个人文档与图片由你保存在本地。

项目与下载：[GitHub Release v1.2.0](https://github.com/HuTaoUnknow/Tmd/releases/tag/v1.2.0)。

## English

Released on 2026-11-05 for Windows 10/11 x64. Tmd combines editable Markdown, local images and a knowledge tree for learning routes, alternatives and detailed notes.

Version 1.2.0 adds Settings → Set as default app (HKCU registration plus the Windows Default Apps / Open with confirmation), single-instance window reuse for repeated launches, external Markdown opening with optional root backups, document find/replace, stronger Chinese-punctuation emphasis and lighter table presentation, faster opening of table-heavy files, nested list markers, Ctrl+click navigation, reference repair after moves, and twenty-two regression groups. Tutorials and the public starter library are refreshed.

Run the Setup EXE for installation. For portable use, extract the entire ZIP into a writable directory and run `Start-Tmd.cmd` or `tree_md.exe`; keep the bundled DLLs and plugins together. Portable data lives beside the program; installed data lives under the system Documents\Tmd folder. Back up the complete library, including hidden relationship metadata, before upgrading.

Use `Ctrl+S` to save and `Ctrl+P` to search. See `README.md`, `docs/USER_GUIDE.md` and `docs/INSTALLATION.md` for details. Verify downloads using `SHA256SUMS.txt`. Packages include public starter examples.
