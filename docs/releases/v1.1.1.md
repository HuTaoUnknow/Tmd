# Tmd v1.1.1 — 版本介绍 / Release introduction

发布日期：2026-10-18。面向 Windows 10/11 x64。

Tmd 把 Markdown 文档编辑、图片和知识树放在同一个本地知识库中。文档页方便阅读和书写，原文页保留可直接编辑的 Markdown；知识树连接学习路线、替代方案、详解与实例。

## 本版更新

- 空行显示：每个元素下方第一个结构空行隐藏，额外空行、普通空格和代码区内部空行继续显示，适合直接阅读与编辑 AI 输出的 Markdown。
- 列表退格：普通无序、有序列表在正文起点按 Backspace，一次转为本行正文并保留文字；有缩进先退一级。空任务框仍先显示完整符号，再退出。
- 标题退格：在第一个井号前按 Backspace，空行上移；遇普通正文合并，例如 `上文### 标题`；遇列表、表格、引用或代码区等元素不合并。标题文字开头的退格还原符号操作继续保留。
- 编辑结构：文档与原文复用命令路由、文本替换及撤销交易，渲染与源码映射共享解析快照。

## 安装与启动

1. 安装版：运行 `Tmd-1.1.1-Windows-x64-Setup.exe`，选择程序目录和快捷方式，之后通过桌面或开始菜单启动。
2. 便携版：完整解压 `Tmd-1.1.1-Windows-x64-Portable.zip` 到可写目录，双击 `Start-Tmd.cmd` 或 `tree_md.exe`。启动器与 EXE、DLL、插件应保留在同一套解压目录中。
3. 便携版的 `md_data` / `md_photo` 位于程序旁；安装版使用系统“文档/Tmd”。升级前可备份整个知识库，保留隐藏的关系文件。
4. `Ctrl+S` 保存当前文档，右侧“文档 / 原文”切换显示，`Ctrl+P` 搜索。详细说明见随包 `README.md` 和 `docs/使用教程.md`。

下载校验使用同页的 `SHA256SUMS.txt`。随包仅包含公开入门示例；个人文档与图片由你保存在本地。

项目与下载：[GitHub Release v1.1.1](https://github.com/HuTaoUnknow/Tmd/releases/tag/v1.1.1)。

## English

Released on 2026-10-18 for Windows 10/11 x64. Tmd combines editable Markdown, local images and a knowledge tree for learning routes, alternatives and detailed notes.

Version 1.1.1 improves structural blank-row handling, exits ordinary lists with one Backspace at the body start, and adds guarded heading movement before the first hash. Shared command routing, source transactions and parsing snapshots keep rendered editing and Markdown source consistent.

Run the Setup EXE for installation. For portable use, extract the entire ZIP into a writable directory and run `Start-Tmd.cmd` or `tree_md.exe`; keep the bundled DLLs and plugins together. Portable data lives beside the program; installed data lives under the system Documents/Tmd folder. Back up the complete library, including hidden relationship metadata, before upgrading.

Use `Ctrl+S` to save and `Ctrl+P` to search. See `README.md`, `docs/USER_GUIDE.md` and `docs/INSTALLATION.md` for details. Verify downloads using `SHA256SUMS.txt`. Packages include public starter examples.
